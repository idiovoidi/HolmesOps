Security and Network Guidelines and Procedures
1. Safe File Handling
• Always save your Unity project files in a dedicated folder.
• Avoid renaming or moving files outside of Unity to prevent broken links.
• Use Unity’s built-in tools to import assets and manage scenes.
• Regularly back up your project to avoid data loss.

2. Version Control Basics
• Use version control software like Git to track changes in your project.
• Commit changes with clear messages describing what was updated.
• Create branches for new features to avoid breaking the main project.
• Push your changes to a remote repository (e.g., GitHub) for safe storage.

3. Network Safety in Unity Multiplayer
• Only use trusted Unity networking packages (e.g., Netcode for GameObjects).
• Never expose sensitive data like passwords or personal information in scripts.
• Use secure connections (HTTPS) when communicating with servers.
• Test multiplayer features in a safe, private network before going public.

4. Best Practices in Shared Development
• Communicate clearly with your team about changes and updates.
• Follow the coding standards provided by your instructor or team lead.
• Avoid editing the same scene or script as someone else at the same time.
• Use Unity Collaborate or Git to sync your work with others safely.
